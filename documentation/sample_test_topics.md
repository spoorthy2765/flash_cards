# Recommended Sample Test Topics

Use these sample topics during presentations and testing to showcase diverse academic domains.

---

## 1. Machine Learning & Artificial Intelligence
- **Topic:** `Machine Learning`
  - *Expected Concepts:* Supervised vs Unsupervised, Bias-Variance Tradeoff, Overfitting, Loss Functions, Gradient Descent.
- **Topic:** `Deep Learning & Neural Networks`
  - *Expected Concepts:* Activation Functions, Backpropagation, CNN vs RNN, Vanishing Gradient, Transformers.
- **Topic:** `Natural Language Processing`
  - *Expected Concepts:* Tokenization, Word Embeddings, Attention Mechanism, BLEU score, Lemmatization.

---

## 2. Core Computer Science Subjects
- **Topic:** `Database Management Systems (DBMS)`
  - *Expected Concepts:* ACID properties, Normalization (1NF to 3NF), Primary vs Foreign Keys, Indexing, Transactions.
- **Topic:** `Operating Systems`
  - *Expected Concepts:* Process vs Thread, Deadlock conditions, Paging & Virtual Memory, Semaphores, CPU Scheduling.
- **Topic:** `Computer Networks`
  - *Expected Concepts:* OSI 7-Layer model, TCP vs UDP, DNS resolution, Subnetting, Handshake protocols.
- **Topic:** `Data Structures & Algorithms`
  - *Expected Concepts:* Time Complexity (Big-O), Hash Tables, Binary Search Trees, Graph Traversals (BFS/DFS), Dynamic Programming.

---

## 3. Programming Languages & Software Engineering
- **Topic:** `Python Programming`
  - *Expected Concepts:* Mutable vs Immutable, Generators & Iterators, Decorators, GIL (Global Interpreter Lock), List Comprehensions.
- **Topic:** `Object-Oriented Programming (OOP)`
  - *Expected Concepts:* Encapsulation, Abstraction, Inheritance, Polymorphism, SOLID principles.
- **Topic:** `Cloud Computing & DevOps`
  - *Expected Concepts:* IaaS vs PaaS vs SaaS, Docker containers, CI/CD pipelines, Horizontal vs Vertical scaling.

---

## 4. Non-CS and General Science (Testing Generalization)
- **Topic:** `Quantum Physics`
  - *Expected Concepts:* Wave-particle duality, Heisenberg uncertainty principle, Quantum entanglement, Superposition.
- **Topic:** `Organic Chemistry`
  - *Expected Concepts:* Electrophiles vs Nucleophiles, Hydrocarbons, Isomerism, Functional groups.
